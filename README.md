## 📓 What Is Psychelog?

**Psychelog** is a free, open-source, **privacy-first mind and mood journal** for **mental wellness**. It gives you a private place to reflect, notice how you feel, and understand your inner world over time.

Built by [LYF Mail](https://lyfmail.com), a [privacy-first digital wellness platform](https://lyfmail.com) serving 50,000+ subscribers across India since 2020, Psychelog extends our mission of **"Every Choice Shapes Tomorrow"** into everyday tools that people can trust.

---

## 🧭 Why Psychelog Exists

- 😔 **Moods and thoughts** are easier to understand when you can look back at them.
- 📝 **Journaling and mood apps** often ask for accounts and store your most personal reflections on servers.
- 🔒 **Your inner life is yours.** A journal is only useful if you can write honestly.

**Psychelog offers honest reflection with privacy by design** — a mind and mood journal built on LYF Mail's privacy-first principles.

## 🚀 Quick Start Guide

### For Users

1. **Visit** [psychelog.lyfmail.com](https://psychelog.lyfmail.com).
2. **Start using Psychelog** straight from your browser.
3. **Add it to your home screen** if your browser offers an install option, for quick access.

### For Developers

1. **Clone the repository**
```bash
git clone https://github.com/lyfmail-official/psychelog.git
cd psychelog
```

2. **Serve locally** with any static file server
```bash
# Python 3
python -m http.server 8080

# Or with Node.js
npx serve .
```

3. **Open in your browser**
```
http://localhost:8080
```

See [`CONTRIBUTING.md`](CONTRIBUTING.md) for contribution guidelines.

## 🤝 Contributing to Psychelog

Psychelog welcomes contributions that respect our core principles:

- **Privacy-first** — never introduce tracking, analytics, or unnecessary data collection.
- **Minimal dependencies** — prefer built-in web platform features over heavy frameworks.
- **Performance-focused** — optimize for low-end devices, slow networks, and limited battery.
- **Accessibility-first** — every feature must work for users with disabilities.
- **Mental health respectful** — no gamification, no metrics pressure, no social comparison.

Please read [`CONTRIBUTING.md`](CONTRIBUTING.md) and [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) before submitting pull requests. To report a vulnerability, see [`SECURITY.md`](SECURITY.md).

## 💬 Frequently Asked Questions

**Q: Is Psychelog really free to use?**  
A: Yes. Psychelog is free to use and open source under the MIT License. It is a project by [LYF Mail](https://lyfmail.com), committed to making useful privacy-first tools accessible to everyone.

**Q: How does Psychelog handle my data?**  
A: Psychelog is built on LYF Mail's **privacy-first principles**: collect as little data as possible and keep control with the user. Because Psychelog is open source, you can inspect exactly how it works in the [source code](https://github.com/lyfmail-official/psychelog).

**Q: Is Psychelog a substitute for therapy?**  
A: No. Psychelog is a **wellness and journaling tool**, not a medical device, diagnostic tool, or replacement for professional care. If you are struggling, please reach out to a qualified mental health professional. In India, **Tele-MANAS (14416)** offers free mental health support. If you are in immediate danger, contact your local emergency services.

**Q: Can I contribute to Psychelog?**  
A: Yes. We welcome developers, designers, writers, translators, and accessibility advocates. Please read [`CONTRIBUTING.md`](CONTRIBUTING.md) and [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) first.

**Q: How do I report a bug or a security issue?**  
A: Open a [GitHub issue](https://github.com/lyfmail-official/psychelog/issues) for bugs. For security vulnerabilities, **do not** open a public issue — follow [`SECURITY.md`](SECURITY.md).
